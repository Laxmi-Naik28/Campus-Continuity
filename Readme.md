# CampusContinuity

AI-Powered Project Knowledge Management and Handover Platform.

## Live Preview
[Open CampusContinuity](https://ai.studio/apps/1d4e64b5-e513-435c-8dac-957bc8b3c4a4)

## Technologies
- React
- TypeScript
- Python
- FastAPI
- Gemini AI

## Features
- Project document upload
- AI-generated project summaries
- Project knowledge management
- AI-assisted task extraction (under development)
- Handover report (under development)
-
## How to Run Locally

### Frontend
npm install
npm run dev

### Backend
pip install -r requirements.txt
uvicorn main:app --reload --port 8001
